# Distribución de los términos

Datos del análisis de distribución del capítulo 6, calculados sobre la anotación final sin las secciones de referencias bibliográficas (un tipo = una unidad normalizada, con todas sus formas).

## Ficheros

- `zipf_termino_{en,es}.csv`: frecuencia y rango de cada tipo de término.
- `zipf_general_{en,es}.csv`: frecuencia y rango del vocabulario general de cada subcorpus.
- `zipf_exponentes.csv`: exponentes de Zipf estimados.
- `saturacion_{en,es}.csv`: curvas de saturación terminológica (proporción de tipos de término reunidos según la proporción de corpus recorrida).
- `*_es_sinrojo.csv`: los mismos datos del español sin los textos de G. Rojo (análisis de sensibilidad).
- `estructura_{en,es}.csv`, `nucleares_{en,es}.csv`: longitud, patrón morfosintáctico e incrustación de las unidades, y términos nucleares.
- `scripts/`: código con que se han obtenido. Lee los ficheros de anotación *token* a *token*, que no se publican (véase el README principal).
